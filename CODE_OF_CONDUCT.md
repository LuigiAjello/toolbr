# Código de conduta

O ToolBR quer ser um lugar acolhedor para qualquer pessoa que queira medir e melhorar agentes de IA em português, seja qual for a experiência, a origem, a identidade ou a forma de se expressar.

## O que esperamos

- Respeito nas discussões, inclusive quando discordamos.
- Crítica ao trabalho, nunca à pessoa.
- Paciência com quem está começando.
- Aceitar correções com boa vontade: um gabarito errado apontado é uma ajuda.

## O que não aceitamos

- Assédio, ofensas, discriminação ou ataques pessoais.
- Expor dados pessoais de alguém sem permissão.
- Usar os ataques do benchmark contra sistemas reais. Eles existem para medir defesas em mundos simulados.

## Como relatar

Abra uma issue privada ou fale com a pessoa mantenedora pelos contatos do perfil do GitHub. Relatos são tratados com sigilo.

Este código se inspira no [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), que vale como referência para os casos não previstos aqui.
